What is Generative AI?

📖

Definition

Generative AI creates new content — text, images, audio, video, or code — rather than just analyzing existing data.

🔀

Traditional vs Generative

Traditional AI classifies, predicts, or detects. Generative AI produces brand-new, original output.

✍️

Text Generation

Models like GPT and Gemini write essays, code, and conversations.

🖼️

Image Generation

Tools like DALL-E turn text prompts into original images.

🔊

Audio Generation

AI can compose music or synthesize realistic speech.

🎬

Video Generation

Emerging models generate short video clips from prompts.

💻

Code Generation

AI assistants write, explain, and debug code from natural language.
